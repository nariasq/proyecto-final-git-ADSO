## 💡 ¿Qué es Git?

Git es un sistema de control de versiones distribuido que permite gestionar cambios en archivos y proyectos de software de forma organizada.  
Permite llevar un historial completo de todas las modificaciones realizadas en el código.  
Cada cambio se guarda como una versión, lo que hace posible volver atrás si algo falla.  
Git ayuda a trabajar en equipo sin que se pierdan los cambios de ningún integrante.  
Funciona de manera local y también se conecta con servidores como GitHub.  
Permite crear ramas para trabajar funciones nuevas sin afectar la versión principal.  
También ayuda a detectar conflictos cuando varias personas modifican lo mismo.  
Git es una herramienta fundamental para desarrolladores y proyectos colaborativos.

## 💻 10 Comandos Básicos de Git

1. `git init`  
   Inicializa un repositorio Git en tu proyecto.

2. `git status`  
   Muestra el estado de los archivos (modificados, preparados, etc.)

3. `git add .`  
   Agrega todos los archivos al área de preparación.

4. `git commit -m "mensaje"`  
   Guarda los cambios con un mensaje descriptivo.

5. `git push`  
   Sube los cambios al repositorio remoto.

6. `git pull`  
   Baja los cambios del repositorio remoto al local.

7. `git clone URL`  
   Descarga un repositorio desde GitHub.

8. `git branch`  
   Muestra o crea ramas.

9. `git checkout nombre_rama`  
   Cambia de rama.

10. `git remote -v`  
   Muestra las URLs del repositorio remoto conectado.

---

## 🔄 Flujo de Trabajo Recomendado

1. Crear o modificar archivos en el proyecto.
2. Revisar los cambios con `git status`.
3. Agregar cambios con `git add .`.
4. Guardar cambios con `git commit`.
5. Subir a GitHub con `git push`.
6. Verificar en GitHub que los cambios se reflejen.
